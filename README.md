One job title, the weirdest one I could think of. This program writes `Professional Mourner for Strangers' Funerals` — 44 characters, a single line, nothing else — to `/output/entry.txt`. Professional mourning is a real job, and the twist is that the mourning is for strangers: a hired stranger, paid to cry over someone they never met. A real-sounding job with one hilariously specific twist, which is exactly what the blind judge rewards.

## Run it

```sh
node main.ts
```
